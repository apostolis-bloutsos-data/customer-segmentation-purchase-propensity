# Data

The original **UCI Online Retail II** Excel workbook is not stored in this
repository. Notebook `01_data_ingestion.ipynb` downloads the source data
directly from the UCI Machine Learning Repository.

The smaller Parquet files generated by the project are retained so that later
notebooks can also be run independently.

## Structure

```text
data/
├── raw/
│   └── .gitkeep
│
├── interim/
│   └── online_retail_raw.parquet
│
└── processed/
    ├── online_retail_clean.parquet
    ├── customer_features.parquet
    ├── customer_segments.parquet
    ├── propensity_dataset.parquet
    └── test_customer_propensity_scores.parquet
```

`raw/` — reserved for original source data. The UCI Excel workbook is
intentionally excluded from version control.

`interim/` — contains the combined, schema-normalized transaction dataset
created during ingestion.

`processed/` — contains cleaned transactions and the customer-level
datasets produced for segmentation and propensity modelling.

To rebuild the project from the original source, run the notebooks in numerical
order from `01` through `06`.
